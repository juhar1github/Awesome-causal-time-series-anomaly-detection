Contributing
============

Thank you for helping maintain this collection.

Adding a paper
--------------

Submit a pull request that updates both README.md and papers.csv.

Required metadata
-----------------

1. Year
2. Method name
3. Full paper title
4. Venue
5. Task
6. Main causal idea
7. Paper URL
8. Code URL
9. Code status
10. Datasets
11. Notes

Verification rules
------------------

1. Prefer the publisher, OpenReview, proceedings, or arXiv page for the paper.
2. Prefer the repository linked by the authors or paper.
3. Mark third-party reproductions as unofficial.
4. Check that the repository actually contains runnable implementation code.
5. Record the repository license.
6. Do not upload or copy external source code into this collection.
7. Avoid duplicate entries and ambiguous acronyms.
8. For a preprint, update the venue when acceptance is officially confirmed.

Pull-request title
------------------

Use this format:

Add METHOD: Full paper title
